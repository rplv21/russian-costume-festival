# Русский костюм — сайт фестиваля

Сайт Всероссийского фестиваля «Русский костюм в городе Ярославле», 16–18 октября 2026.
Astro (SSR, `@astrojs/node`, standalone), деплой на TimeWeb App Platform по Dockerfile — тот же стек, что у yaropolov-site.

## Команды

| Команда           | Действие                              |
| :---------------- | :------------------------------------- |
| `npm install`      | Установка зависимостей                 |
| `npm run dev`      | Локальный сервер на `localhost:4321`   |
| `npm run build`    | Сборка в `./dist/`                     |
| `npm run preview`  | Просмотр собранной версии              |
| `npx astro check`  | Проверка типов                         |

## Переменные окружения (`.env`, не в репозитории)

| Переменная                        | Назначение                                              |
| :--------------------------------- | :-------------------------------------------------------- |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | Логин админ-панели `/admin`. Без переменных — дефолт в `src/lib/adminAuth.ts`; в проде обязательно задать свои. |
| `RESEND_API_KEY`                    | Отправка PDF-билетов на почту при бронировании — через HTTP API [Resend](https://resend.com), не SMTP (TimeWeb App Platform блокирует исходящие SMTP-подключения, проверено на портах 465 и 587). Без переменной бронирование всё равно работает — билет просто доступен только по кнопке скачивания. |
| `MAIL_FROM`                          | Адрес отправителя писем с билетами, например `Русский костюм <bilety@kostum76.ru>`. Домен должен быть подтверждён в Resend (DNS-записи на reg.ru). Без переменной — дефолт в `src/lib/mail.ts`. |
| `GITHUB_DATA_TOKEN`                 | **Обязательна в проде.** TimeWeb App Platform не даёт постоянного диска — без этой переменной брони пишутся в файл внутри контейнера и стираются при следующем деплое. Токен (fine-grained PAT, только `contents:write` на репозиторий `rplv21/russian-costume-festival-data`) переключает `src/lib/bookingStore.ts` на чтение/запись `bookings.json` через GitHub API вместо локального файла. |
| `GITHUB_DATA_OWNER` / `GITHUB_DATA_REPO` / `GITHUB_DATA_BRANCH` | Куда именно пишутся брони — по умолчанию `rplv21` / `russian-costume-festival-data` / `main`, переопределять не нужно, если репозиторий не переименовывался. |
| `PORT` / `HOST` / `NODE_ENV`        | Уже заданы в `Dockerfile`, переопределять не нужно.        |

## Источник контента

Весь фактический контент (даты, номинации, сроки, контакты, программа) — в
[`src/data/site.ts`](./src/data/site.ts), сверен с официальным «Положением о проведении
Всероссийского фестиваля «Русский костюм в городе Ярославле»» от 19.03.2026
(в проде отдаётся как `public/documents/polozhenie-russkiy-kostyum-2026.pdf`).
Геометрия зала ТЮЗа (для бронирования билетов) — отдельно в `src/data/seating.ts`.

Любые изменения дат/цен/контактов проверять по актуальному Положению, если клиент его обновит.

## Структура

- `src/data/site.ts` — единственный источник контента; `src/data/seating.ts` — схема зала.
- `src/components/DollScroller.astro` — фоновый слой с куклой (статичная картинка,
  `public/dolls/doll-main.webp`), не мешает чтению текста.
- `src/components/Header.astro` / `Footer.astro` — шапка и подвал с навигацией.
- `src/components/SeatMap.astro` — интерактивная схема зала для бронирования (`/bilety`).
- `src/pages/admin/` + `src/pages/api/admin/` — админ-панель: занять/освободить место,
  просмотр брони, скачивание билета конкретного места, выгрузка всех броней в Excel
  (`src/lib/xlsxWriter.ts` — свой генератор `.xlsx` без внешних зависимостей).
- `src/lib/bookingStore.ts` — хранилище броней, JSON-файл `data/bookings.json`
  (не в репозитории — содержит ФИО/email реальных зрителей).
- `src/lib/tickets.ts` — генерация PDF-билетов (`pdf-lib` + `@pdf-lib/fontkit`).
- `public/documents/` — официальные формы заявок (docx) и Положение (pdf), статика.
- `public/fonts/druzhok.otf` — шрифт заголовков, самостоятельно захостен через `@font-face`.

## Продакшен: на что обратить внимание

1. **Брони хранятся не на диске контейнера, а в приватном GitHub-репозитории**
   `rplv21/russian-costume-festival-data` — TimeWeb App Platform не даёт постоянного диска,
   контейнер пересобирается с нуля при каждом деплое. Обязательно задать `GITHUB_DATA_TOKEN`
   в переменных окружения TimeWeb, иначе `bookingStore.ts` молча откатится на локальный файл
   и брони снова будут стираться при следующем деплое (в лог при этом пишется предупреждение).
2. **Домен** — куплен `kostum76.ru`, уже прописан в `astro.config.mjs` (используется для
   sitemap и canonical-ссылок). Осталось направить DNS на IP приложения в TimeWeb.
3. **Почта не настроена** — задать `RESEND_API_KEY` (и при необходимости `MAIL_FROM`) в переменных
   окружения TimeWeb, иначе письма с билетами не уходят (билет всё равно доступен по кнопке).
   Домен-отправитель нужно подтвердить в Resend через DNS-записи на reg.ru.
4. **Admin-креды** — сменить `ADMIN_USERNAME`/`ADMIN_PASSWORD` с дефолтных на свои через
   переменные окружения TimeWeb перед тем, как раздавать доступ к `/admin`.
5. **18 октября (гала-концерт)** — платный день, страница `/bilety` бронирует только
   бесплатные 16 и 17 октября; ссылка на продажу билетов на гала пока не подключена.
6. **Прошедшие фестивали** — фестиваля 2025 года не было, в списке остался только 2024-й
   (`src/pages/proshedshie/2024.astro`) с полной фотогалереей (414 фото, `public/gallery/2024/`,
   исходники — локально в `РК.2024/`, не в репозитории).
7. **Галерея** — раздел `/galereya` пуст до самого фестиваля, ссылается на VK.
8. Проверить, что e-mail для приёма заявок (`yarruskostum@yandex.ru`) и для
   подтверждения участия (`odnt.folk@mail.ru`) не перепутаны — в Положении это
   два разных адреса с разными задачами.
